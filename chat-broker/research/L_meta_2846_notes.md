## Model and elementary observations
Let F be the edge function of a nonempty C4-free bipartite graph, with v active vertices. In a least exact binary positive circuit every gate is used, the output is a gate, every active variable is used, and inactive variables can be pinned to zero and simplified away. Any unused gate or a gate with two equal operands can be deleted. These are mathematical observations, not machine-checked Lean lemmas. Every gate must occur in an accepting proof tree of at least one positive edge: otherwise set the gate to false, simplify constants, and retain all edge positives, with no new positive rows by monotonicity. Every gate output therefore has some positive edge row.

A wire is safe if its function implies F. An AND gate cannot read a safe operand in a least circuit: replace the AND with that operand, which increases the signal but does not change any negative row, and delete the gate. The T condition forces every OR reader of any safe wire into the terminal OR tree, and T's strictly increasing unique-reader chains end at the output. A safe wire cannot have multiple reads in a least top-stuck circuit: all reads must be in that OR tree, and one occurrence can be removed by idempotence of OR, collapsing the relevant OR gate. If all AND gates are safe, none can be under another AND; the operands are OR-only, and pure-shore test rows force the two nonempty operand supports to be on opposite shores.

Every AND-OR circuit computing F has at least v-1 gates by counting edges of its connected live dependency DAG. If it has v-1 gates the circuit is a tree and each active input occurs once. Every AND participates in an edge witness, whose tree has exactly two leaves and one AND; hence no nested AND, and the required pure OR pools exist. More generally, if every edge has a read-once accepting proof tree, select one per edge; prune any unused gate. Each surviving AND lies on an OR-only path to the output, so it is safe. This gives the required conclusion by the preceding argument.

## Partial result: at most one repeatedly read wire (unformalized)
Claim: a least top-stuck circuit in the assigned model is normal if at most one wire is read more than once (any multiplicity). Consequently this includes the v-1 and v gate cases. This is a mathematical proof attempt, not a verified Lean result.

First suppose the repeated wire is a raw variable t. The live circuit is a formula, every other variable occurs once. If no AND has t in both branches, all AND supports are disjoint, so every accepting edge proof is read-once. Otherwise choose such an AND Q=Q1 AND Q2. The two branch variable sets meet only in t. Setting a particular occurrence of t to false and simplifying removes a gate; leastness therefore forces some edge involving t to require an occurrence in Q. Hence Q is true on some edge {t,b}, and at least one branch is true on the singleton t. If both are true on t alone, each has an OR-only path from an occurrence of t to its root, and can be written t OR Ai by factoring that path (if Ai is absent, the branch is t). Factoring (t OR A1) AND (t OR A2)=t OR (A1 AND A2) saves a gate, including degenerate cases. Thus exactly one branch, Q1, is true on t alone. Q2 is false on singleton t, so b lies in Q2's other variables B2. Q is false on every singleton because the branches otherwise have disjoint variables.

If Q has an AND ancestor, its sibling may see t but none of the private variables B inside Q. An edge involving a private variable cannot be accepted if its other endpoint is outside Q and not t (Q would see only a singleton), or if both endpoints are private inside Q (the AND sibling sees all zeros). Every private variable is essential, hence all have neighbor t. Replace Q by t AND OR(B), a safe signal preserving every edge row on which Q was needed and false on negative rows. This uses |B| gates instead of |B|+r-1, where r>=2 is the number of t occurrences in Q. Contradiction.

If Q has no AND ancestor, Q is safe. Every private variable in Q1 must participate in an edge to B2 (Q2 is false on t alone); hence Q1 is true on each of its singleton variables and is their OR, including t. A replacement by their pure OR saves gates unless t occurs there exactly once, in which case the branch is already syntactically OR-only. Every b in B2 is essential via an edge to t or a private Q1 variable. Thus Q2(b)=true or Q2(t,b)=true, and safety of Q plus Q1(t)=true implies that every b in B2 is adjacent to t. Partition B2 into S (Q2 true on singleton) and V (the others). Replace Q2 by OR(S) OR (t AND OR(V)), omitting empty terms. This is pointwise <=Q2 by monotonicity, and preserves all edge rows needed by Q. If V is empty, this saves at least one gate. If V is nonempty, the replacement has |B2| gates, so it saves a gate if the branch has multiple t occurrences. In the remaining case Q2 is read-once and false on t alone. Every other variable has a singleton or t-pair witness; hence there is exactly one AND, on the t path, with operands t and OR(V), and the OR-only siblings above it are the singleton variables S. This AND is safe. If S is empty, Q2 implies Q1 and Q is redundant. If S is nonempty, its immediate OR reader is inside Q2 and is forced into T, but its unique path reaches the AND Q, contradicting T. This rules out an AND reconvergence of the single repeated raw variable.

If the repeated wire is an internal gate h, its predecessor cone is a read-once tree on a private input set A, |A|>=2; these inputs have no other occurrence outside the cone. The rest is a formula R(t,B) with one repeated variable t standing for h. For any fixed B, the unary monotone function R(t,B) is 0, t or 1. If G[A] has an edge, fixing B=0 shows h=F_{G[A]}, a safe wire, contradicting multiple reads in a least top-stuck circuit. Otherwise for any b in B adjacent to some A vertex, fixing B to singleton b shows h=OR(N(b) intersect A). All A vertices are essential, so this is OR(A); all A share their neighbors, and C4-freeness implies exactly one common neighbor. Contract this private OR cone to t, a degree-one vertex in the quotient graph. The quotient circuit is least (a smaller one could be composed with h), top-stuck (truth/safety of every remaining wire is preserved by the surjective substitution t=h), and C4-free. Apply the raw repeated-variable case and expand the pure-shore OR cone. This proves the conditional result modulo formalization.

## Second partial result: pure CNF circuits cannot be least for a non-star graph (unformalized)
For a nonempty C4-free bipartite graph with active shores P,L, write p,l,v=p+l,m=|E|, tau=maximum matching=minimum vertex cover, c=number of minimal vertex covers. The normal star-cover circuit has at most m+tau-1 gates (assign each edge to a covering endpoint, one AND per nonempty star, sum of OR leaf costs m-number of stars, then a top OR tree). A pure CNF circuit, meaning a conjunction computed by an AND-only layer of OR-only clauses, must realize every prime clause corresponding to a minimal vertex cover. Both pure shores P,L are minimal covers. Their disjoint OR cones cost at least v-2; each of the c-2 other mixed prime clauses requires a distinct additional OR gate; the AND layer needs at least c-1 gates. Thus size >= v+2c-5.

Claim for any non-star C4-free bipartite graph: v+2c-5 >= m+tau. This makes pure CNF strictly more expensive than the normal upper bound. Proof attempt:
c equals the number of distinct unions of row neighborhoods N(a), including empty/full, via maximal independent sets (a union U determines the closed row set {a:N(a) subset U} and the complementary line set L\\U). Distinct row neighborhoods of size >=2 are unique and pairwise intersect in <=1. Let r be the count of such rows; s the number of distinct singleton neighborhoods. For each high row a, let d_a count its line neighbors of degree >=2 and b_a its private line neighbors. Let q be the number of high rows with b_a>0. Write l1 for the number of internal lines, e0 for isolated edge components. Counting line leaves gives m-p-l+tau=sum_high(d_a-1)-l1-e0+tau. A matching uses at most l1 internal lines, q private leaves attached to high rows, and e0 isolated edges. So m+tau-v <= sum_high(d_a-1)+q <= r+q+H, where H=sum_high max(0,d_a-2).
If r=0, the graph is a union of s stars, m+tau=v, c=2^s; non-star means s>=2, so inequality holds. If a high row equals the full union, r=1, all other rows are singletons; the graph is a tree, tau<=1+s, c>=2^s+1 when s>=1, and 2c-5>=s>=m+tau-v. The s=0 case is a star. Otherwise full, empty, r high and s singleton neighborhoods are distinct, giving c>=r+s+2.
If H=0 and r-q+2s>=1, then 2c-5>=r+q. If r=q and s=0, all high rows have private leaves; their unions yield c>=2^r, enough for r>=3. For r=2, at most one internal line is shared by the two rows, so sum(d_a-1)+q<=2 and c>=4 suffices; r=1 is the already handled star case.
For H>0, let h=count of rows with d_a>=3, d=max d_a>=3. Extra unions beyond the r+s+2 baseline number at least binom(h,2)-1: a union of two of these rows uniquely determines the pair since a third such row intersects each in <=1; at most one union is full. Extra unions also number at least 2^d-d-2: project onto the internal lines of a row with d such neighbors; other rows meet this set in at most one line, and each internal line has another row; every proper subset of size 2..d-1 is attainable as a union projection, distinct from the baseline. Let e be the maximum of these two bounds. Since H<=h(d-2), 2e>=H+1: for h>=d use h(h-1)-2 >=h(d-2)+1; for h<d use 2(2^d-d-2)>=(d-1)(d-2)+1. Then 2c-5>=2r+2s-1+2e>=r+q+H. This completes the arithmetic. Check proof carefully before treating as a new lemma.
This is not enough for L-meta-2846: an arbitrary circuit need not be pure CNF; safe blocks can have mixed AND/OR structure, shared signals, and higher minterms already covered by other edges.
